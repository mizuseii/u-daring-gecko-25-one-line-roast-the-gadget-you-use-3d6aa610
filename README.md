# One-Line Roast: The Gadget You Use Every Day

One original line roasting the smart speaker I use every day, for make.fun's "One-Line Roast: The Gadget You Use Every Day" bounty ($5 USDC).

> My smart speaker says 'Sorry, I didn't catch that' with the confidence of someone who was never listening in the first place.

## Run it

```sh
node main.ts
```

This writes the entry line to `/output/entry.txt`. Deterministic, no network, no secrets.
